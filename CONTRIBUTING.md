# Contributing to Waveify

Thanks for your interest in Waveify.

## Contribution rules

1. Create a focused branch.
2. Keep changes small and well-tested.
3. Open a clear pull request with the motivation and scope.
4. Do not submit code copied from proprietary or third-party projects without permission and a compatible license.
5. Declare the origin of any reused code or assets.
6. Never commit secrets, private keys, tokens, credentials, or environment-specific configuration.

## Standards

- Keep the code readable and maintainable.
- Prefer original implementations or code that is clearly compatible with the project license.
- Update tests or documentation when behavior changes.
- Validate the relevant commands for the area you touched.
